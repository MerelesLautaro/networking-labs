# Networking Labs

Repositorio personal de prácticas y laboratorios de redes informáticas realizados con **Cisco Packet Tracer**.

El objetivo es documentar mi aprendizaje sobre redes, switching, routing, segmentación, servicios de red y seguridad, mediante configuraciones prácticas y pruebas de conectividad.

## Tecnologías y herramientas

- Cisco Packet Tracer
- Cisco IOS CLI
- Ethernet y TCP/IP
- VLANs y Trunking
- DHCP
- ACLs
- Routing
